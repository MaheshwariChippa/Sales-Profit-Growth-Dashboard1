# Business Intelligence Dashboard in Tableau

This repository contains an interactive dashboard created using Tableau to visualize key business KPIs such as Sales, Profit, and Growth.

## Files:
- **Sales_Profit_Growth_Dashboard.twbx**: Tableau Packaged Workbook that includes the dashboard and data.
- **Summary.pptx**: PowerPoint presentation explaining the dashboard and KPIs.
- **Data/**: Folder containing the data files used in the dashboard (if applicable).

## Dashboard Overview:
This dashboard allows business stakeholders to analyze the performance of key metrics, including:
- **Sales**: Total revenue generated.
- **Profit**: Earnings after all expenses.
- **Growth**: Year-over-year or month-over-month performance.

## Features:
- **Interactive Filters**: Allows users to filter data by region, product category, and time period.
- **Time-Series Analysis**: Visualizes trends over time to track sales and profit growth.
- **KPI Cards**: Displays key metrics like total sales, profit, and growth at a glance.

## Setup Instructions:
1. Download and open the `Sales_Profit_Growth_Dashboard.twbx` file in Tableau Desktop.
2. If you want to use your own data, make sure to place the data files in the `Data/` folder and link them to the workbook.
3. For interactive filters, use the slicers in the dashboard to explore different views.
